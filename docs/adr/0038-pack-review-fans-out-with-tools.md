# Pack drain-end review fans out three axes with the tools, not a pasted diff

The drain-end review node is now three reviewers, one per axis: bugs and incorrect assumptions, missing tests, cross-file breakage. Each gets its own persona naming its axis and refusing the other two, its own session (`drain-review-1..3`), and they run concurrently. Bun writes one `review.md`: `## <n>. <axis>` plus that reviewer's own final message (`opts.text`, session log as fallback, `lastError` as the last resort). A reviewer that throws writes `review error: <msg>` in its own section and does not take the other two down.

Reviewers are handed the range, not the diff: `Review the range <base>...HEAD (HEAD = <sha>)` plus a `git log --oneline` menu. Nothing is pasted, so the 400KB diff cap is gone with it: each reviewer reads `git log`, `git diff`, `git show`, `cat` and `rg` for itself, per file, at either revision. Pi's review session therefore gains bash (tools `read`, `grep`, `find`, `ls`, `bash`; `useBash: true`); the contract - never write, no commits, no mutating git, no spawned agents - is instruction-only for both runners now. One persona text serves both; `runner` only changes mechanics behind the seam.

The implement persona on dsh reads `~/.pi/agent/skills/tdd/SKILL.md` at run time - the same tree Pi's own loader reads - dropping the loader front-matter and the paragraph that points into the codebase-design tree (interface design belongs to ticket writing, not to a node executing a ticket, and it is dead prose for a runner with no skill loader). The inlined body stays as the fallback for a machine with no pi skill tree. Pi's implement and conflict prompts are byte-identical to before (701 / 1061 bytes).

Preflight is unchanged: no `review-base` skips, an unreadable base is `review error: git diff ...`, an empty range (`git diff --stat`) is `empty diff ..., skipped` before any agent is spent. Pack still does not parse the report; settle stays the Git contract. Review wall clock 30 minutes per reviewer; Archon node timeout 2000000ms.

Supersedes ADR-0036.

Rejected: keeping the pasted diff (three copies of a capped diff in three prompts); one agent given all three axes (three near-duplicate reports for 3x the tokens); three YAML review nodes plus a merge node (more node semantics to validate for a report a human reads); one artifact per axis (the consumer goes from one file to three); a synthesizer reviewer (a fourth session to dedupe prose); Pi keeping its bash-less allowlist (a reviewer that cannot read git history); running reviewers in a scratch worktree of Main (worktree plus `.venv` machinery to isolate a write the contract already forbids); a bash command allowlist on Pi only (two runners, two rules again, and normal pipelines keep tripping it).

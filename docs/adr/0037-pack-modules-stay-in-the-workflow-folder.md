# Pack modules stay inside a workflow folder until archon learns `.shared/`

Archon's authoring docs (`archon-cli` skill) prescribe `<pack>/.shared/` for pack-level `.ts` modules. The deployed archon (v0.10.1) has no pack-level shared-module concept. Its loader refuses dot-prefixed pack directories (`Invalid packaged workflow directory 'ticket-dag/.shared'`) and requires every pack subdirectory to hold exactly one `.yaml`/`.yml` (`Packaged workflow 'ticket-dag/shared' must contain exactly one .yaml or .yml file (found 0)`), so a directory that is not a workflow cannot exist under the pack. `shared/`, `shared/sub/` and `defaults/` fail the second check too. The loader never validates imports and never looks inside a workflow folder, so `scripts/` and `tests/` are legal. The authoring docs describe a layout newer than the deployed binary: trust the binary, not the skill docs.

Modules therefore live in `ticket-dag-drain/scripts/`. `ticket-dag-execute/scripts/implement.ts` and `conflict.ts` re-export those bodies across the pack folder (`../../ticket-dag-drain/scripts/…`), a path the loader does not know about, so it is declared in both shims and covered end to end: `drain-repro` spawns both shims by path and asserts exit code, stderr and stdout token, so a broken import fails the suite. Copy the pack whole (`cp -r`, never a symlink, ADR-0032); copying one workflow folder alone breaks its imports.

The migration is written and parked at commit `c3c877e` on branch `pi-subagents/c5-shared-layout-38b9764-8290-s0-t0`: fifteen modules into `<pack>/.shared/`, `../../.shared/x.ts` imports, only `script:` targets left in each workflow folder, both shims deleted. It passed all ten repro scripts; the only failure was the loader refusing `.shared/`. Cherry-pick it once the deployed archon supports that layout; do not merge it before.

Rejected: upgrading archon to make the refactor possible; a non-dot `shared/` (still needs one YAML, and the cross-folder import survives); copying implement/conflict into execute (~120 duplicated lines); moving the bodies into execute and leaving drain the shims (more imports would cross instead of two); keeping a `.scratch/` note instead of this record.
